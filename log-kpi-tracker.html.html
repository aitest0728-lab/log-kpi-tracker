Tableau Connection

Do not commit real credentials to this file or a public repo. Values entered here are kept only in this browser tab's memory — they reset on refresh and are never written back into the HTML. For a deployed site, keep the API key out of the page entirely; pull data on a schedule into data.json instead (see chat for the recommended pattern).
This panel calls Tableau's REST API sign-in and view-data endpoints directly from the browser. Most Tableau Server/Cloud deployments block cross-origin browser requests like this by default (CORS), so this is best used for local testing against a server you control, or once you've allow-listed this page's origin. If the call is blocked, the site falls back to data.json automatically.
